# RouteMate Frontend

A Vite + React + TypeScript scaffold styled after your Figma prototype.

## Start
```bash
npm install
npm run dev
```

## Main files to update later
- `src/data/mockData.ts` → replace mock data with API responses
- `src/pages/*` → connect page actions to your backend
- `src/styles/global.css` → tweak spacing/colors/shadows
- `src/types/index.ts` → keep frontend types aligned with backend DTOs
